Getting Started

Quick setup guide for developers

Installation & Setup

# Install dependencies
pnpm install

# Database setup
pnpm drizzle-kit generate
pnpm drizzle-kit migrate

# Seed demo data
npx tsx server/seed_data_sql.ts

Running the App

# Development mode
pnpm dev

# Train ML model
python3 server/ml_model.py

# Production build
pnpm build
pnpm start

Local Access: http://localhost:3000

Requirements: Node.js 22+, MySQL, Python 3.11+
